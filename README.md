# Protoblocks

Protoblocks is a cross-platform block-building sandbox game inspired by the creativity and social play of Roblox, built to run on Windows, Android, and Linux.

The goal of the project is to create a fun, accessible, and expandable game platform where players can explore, build, customize, and share worlds using simple block-based tools and a social gameplay loop.

## Why Protoblocks?

Protoblocks is designed for players who enjoy:

- Building custom worlds and structures from blocks
- Exploring user-created maps and experiences
- Social interaction inside shared game spaces
- Lightweight multiplayer and creative sandbox play
- Running the same creative experience across multiple devices

## Platforms

Protoblocks is being developed with cross-platform support in mind:

- Windows
- Android
- Linux

This makes it easier to build a player base across desktop and mobile devices while keeping the core experience consistent.

## Core gameplay ideas

- Block-based world building
- Player avatar customization
- Explore-and-build gameplay loop
- Community-driven worlds and experiences
- Simple social features for friends and groups
- Extensible systems for future game modes and content

## Current status

Protoblocks is in active development and the project is being shaped into a playable sandbox experience.

This repository currently serves as the foundation for the project and will continue to grow as gameplay systems, tooling, and documentation are added.
